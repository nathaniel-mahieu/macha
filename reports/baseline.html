Baseline & noise

Orbitrap centroid data never contains zeros: anything below the noise threshold is simply absent. The baseline treats an absent point as an upper bound (≤ detection floor), not as a zero and not as the last observed value.

What it does

Asymmetric Whittaker smoothing (arPLS weights) with a second-difference penalty, solved in O(n) by a banded LDLᵀ factorisation compiled with numba and run over every trace in one call. Observed points get arPLS weights, so peaks are down-weighted. Censored points (scans where the trace has no centroid) are handled as one-sided information: they gently pull the baseline toward a low value while it sits below the detection floor, and become hard constraints at the floor if the baseline tries to rise above it, since a baseline above the floor would have been observed. The detection floor itself is estimated per scan block and m/z block as a low quantile of reported intensities. The original macha filled gaps by carrying the last value forward (LOCF) before an IRLS baseline, which props the baseline up after every peak.
