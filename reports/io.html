What it does

read_mzml parses mzML in a single forward pass with an event-driven XML parser, decoding binary arrays (zlib, 32/64-bit, MS-Numpress linear/pic/slof) only for MS1 spectra and skipping MS2 without decoding, so DIA and DDA files reduce to their MS1 content as they stream. fetch_ms1 does this over HTTP with retry and backoff, which is how the public Astral data below was obtained without storing raw files. Spectra are sorted by m/z and packed into an MSRun: flat m/z / intensity arrays with per-scan offsets (CSR), retention times, scan windows and metadata. stitch_scans merges multi-range acquisitions (several MS1 scans per cycle covering different m/z windows, the original rawdata(splits=…)) into one scan per cycle. write_mzml exports a run back to mzML.
