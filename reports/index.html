Modules

Each module is usable on its own; macha.pipeline only fixes the order.

  • macha.io / MSRun: streaming mzML (local, gzip, HTTP), MS-Numpress, CSR run container, multi-range stitching, mzML export.
  • macha.traces: ROI detection as multi-target tracking with linear assignment and a self-calibrated, intensity-dependent m/z precision model (replaces rectroi / webtrace / dengroup).
  • macha.baseline: censoring-aware asymmetric Whittaker baselines with Tobit imputation of unreported scans, detection-floor and noise estimates (replaces LOCF + IRLS / alpha-hull).
  • macha.peaks: persistence (prominence) peak detection, feature table with m/z standard errors, optional EMG mixture refinement (replaces scale-space seeding + skew-normal refits).
  • macha.annotate: modulo mass-difference graph (isotopes, adducts, losses, charge states, multimers, homologous series) with decoy-calibrated two-groups Bayesian edge posteriors and MAP graph partitioning into compounds (extends mz.unity).
  • macha.annotate.scan_graph: the same rules tested between centroids scan by scan with ±1 scan bridging; relations aggregated over time, decoy-calibrated, triangle-supported, and partitioned into compounds in graph space before any peak detection, under an elution-time prior learned from the run's peak width.
  • macha.align: drift-trend mixture model of retention-time warps with probabilistic, one-per-run correspondence and membership probabilities (replaces grtgmzcor / warpgroup / warpcombine DTW).
  • macha.synth: the ground-truth simulator behind every accuracy number: fine-structure isotopes, adducts, EMG elution, Orbitrap-like coalescence, precision and censoring, multi-run batches with class-specific drift.
