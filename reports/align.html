Alignment

Retention-time drift is modelled as a mixture of drift trends shared by subsets of compounds, learned by EM on unambiguous anchors; correspondence is then solved in each m/z channel with the posterior predictive RT of each group, giving every feature a membership probability.

What it does

Drift trends, not m/z channels. The original warpgroup/warpcombine aligned each m/z group separately with DTW (noisy, expensive, blind to what other compounds do), and grtgmzcor fitted one global curve per run. Here each compound belongs to a latent drift class; its RT in run j is μ + wkj(μ), where wkj is a P-spline warp shared by every compound of class k, centred across runs so μ is the consensus time. EM on anchors (features unambiguous in m/z within a wide RT window, matched across runs) alternates class responsibilities, penalised weighted least squares per (class, run), consensus times, a heteroscedastic noise scale (each anchor's apex uncertainty from its width and SNR) and an outlier component for gross mismatches. BIC picks the number of classes. Per-run m/z calibration (smooth ppm offset vs RT) is fitted on the same anchors.

Bayesian group membership. Pooled, calibrated features are cut into m/z channels. In each channel, groups are grown run by run and then refined by leaving each run out and re-assigning it, always by linear assignment, with at most one feature per run and group. The cost is the negative log posterior predictive density: m/z is Gaussian, and RT follows a Student-t whose centre and spread come from the mixture over drift classes. A group's class posterior comes from how well its members fit each class, so a young or ambiguous group predicts broadly and a well-determined one predicts tightly. Every feature then receives a leave-one-out membership probability against all compatible alternatives, including "belongs to no group". After a first pass, the drift model is re-learned from all confident groups (many more than the anchors) and correspondence is solved again.

Identifiability. Where two class trends cross, class labels can swap between RT regions without changing any prediction. Class recovery is therefore scored locally (ARI within 60 s windows); the RT predictions themselves are unaffected.

Accuracy against ground truth

Correspondence is scored on pairs of features from different runs: a pair is correct when both come from the same true ion. RT spread is the RMS deviation of each method's aligned RTs around their true ion's mean.
